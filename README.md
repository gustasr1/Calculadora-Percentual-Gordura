# Calculadora de Percentual de Gordura Corporal: Para Que Serve?

Uma **calculadora de percentual de gordura corporal** é uma ferramenta útil para avaliar a composição do seu corpo, indo além do peso tradicional medido na balança. Ela ajuda a estimar a proporção de gordura em relação a outros tecidos (como músculos, ossos e água) no seu organismo.

## Principais Usos:

### 1. **Avaliação de Saúde**
   - Identifica riscos associados a gordura corporal alta (ex.: diabetes, doenças cardiovasculares).
   - Também pode alertar para gordura muito baixa (impactando hormônios, imunidade).

### 2. **Acompanhamento de Fitness**
   - Ideal para quem busca ganho muscular ou perda de gordura.
   - Mostra progresso real, já que o peso sozinho não diferencia gordura de músculo.

### 3. **Definição de Metas Realistas**
   - Ajuda a estabelecer objetivos com base em faixas saudáveis (ex.: 10-20% para homens, 20-30% para mulheres).

### 4. **Comparação Mais Precisa**
   - Melhor que o IMC, que não distingue gordura de massa magra.
